**SQL:**

```sql
SELECT SUM(score) AS total_score
FROM students
WHERE age > 25;
```

If they want per-student:

```sql
SELECT student_id, SUM(score) AS total_score
FROM students
WHERE age > 25
GROUP BY student_id;
```

**MongoDB (aggregation):**

```js
db.students.aggregate([
  { $match: { age: { $gt: 25 } } },
  { $group: { _id: null, totalScore: { $sum: "$score" } } }
]);
```

Per-student:

```js
db.students.aggregate([
  { $match: { age: { $gt: 25 } } },
  { $group: { _id: "$studentId", totalScore: { $sum: "$score" } } }
]);
```

One-liner talking point: *"`match‘before‘match` before ` match‘before‘group` so the pipeline can use an index on `age` and shrinks the working set before aggregation."*
