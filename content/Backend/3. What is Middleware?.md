Middleware is a **function that executes between receiving a request and sending a response**.

It can:

- Modify the request (`req`)
- Modify the response (`res`)
- Execute logic
- Call the next middleware
- End the request-response cycle

---

## Request Flow

```
Client Request
      ↓
Middleware 1
      ↓
Middleware 2
      ↓
Middleware 3
      ↓
Route Handler
      ↓
Response
```

---

## Express Middleware Example

```js
const express = require('express');
const app = express();

const logger = (req, res, next) => {
    console.log(`${req.method} ${req.url}`);
    next(); // pass control
};

app.use(logger);

app.get('/users', (req, res) => {
    res.send('Users List');
});
```

Request:

```
GET /users
```

Output:

```
GET /users
```

Response:

```
Users List
```

---

## Why Use Middleware?

Instead of writing the same code in every API:

❌ Bad

```js
app.get('/users', (req, res) => {
   validateToken();
   logRequest();
   res.send('users');
});

app.get('/orders', (req, res) => {
   validateToken();
   logRequest();
   res.send('orders');
});
```

✅ Good

```js
app.use(validateToken);
app.use(logRequest);
```

Reusable and maintainable.

# Common Middleware Types

## 1. Logging Middleware

```js
const logger = (req, res, next) => {
    console.log(`${req.method} ${req.url}`);
    next();
};
```

Used for:

- Auditing
- Debugging
- Monitoring

---

## 2. Authentication Middleware

```js
const auth = (req, res, next) => {
    const token = req.headers.authorization;

    if (!token) {
        return res.status(401).json({
            message: 'Unauthorized'
        });
    }

    next();
};
```

Usage:

```js
app.get('/profile', auth, (req, res) => {
    res.send('Profile');
});
```

---

## 3. Authorization Middleware

Authentication = Who are you?

Authorization = What can you access?

```js
const isAdmin = (req, res, next) => {
    if (req.user.role !== 'admin') {
        return res.status(403).send('Forbidden');
    }

    next();
};
```

---

## 4. Body Parser Middleware

Without it:

```js
console.log(req.body);
```

Output:

```js
undefined
```

Enable parsing:

```js
app.use(express.json());
```

Now:

```json
{  "name": "John"}
```

becomes:

```js
req.body.name
```

---

## 5. [[1. What is CORS?|CORS]] Middleware

Allows frontend applications from other domains.

```js
const cors = require('cors');

app.use(cors());
```

Example:

```
Frontend:
http://localhost:3000

Backend:
http://localhost:5000
```

Without CORS:

```
Blocked by browser
```

---

## 6. Error Handling Middleware

Special middleware with 4 parameters.

```js
app.use((err, req, res, next) => {
    console.error(err);

    res.status(500).json({
        message: 'Internal Server Error'
    });
});
```

Usage:

```js
throw new Error('Something failed');
```

# Middleware Execution Order

```js
app.use(middleware1);
app.use(middleware2);

app.get('/users', handler);
```

Request:

```
middleware1
      ↓
middleware2
      ↓
handler
```

Order matters.

# Route-Level Middleware

Applied only to specific routes.

```js
app.get(
  '/admin',
  auth,
  isAdmin,
  (req, res) => {
      res.send('Admin Dashboard');
  }
);
```

Flow:

```
Request
  ↓
auth
  ↓
isAdmin
  ↓
Controller
```

# Real Production Example (JWT)

```js
const jwt = require('jsonwebtoken');

const authenticate = (req, res, next) => {
    try {
        const token =
          req.headers.authorization?.split(' ')[1];

        const user =
          jwt.verify(token, process.env.JWT_SECRET);

        req.user = user;

        next();
    } catch {
        res.status(401).json({
            message: 'Invalid Token'
        });
    }
};
```

Usage:

```js
app.get('/orders', authenticate, getOrders);
```

# Common Interview Questions

### Q: What happens if `[[8. next()|next()]]` is not called?

```js
const middleware = (req, res, next) => {
   console.log('Hello');
};
```

The request hangs because Express never moves to the next middleware or route handler.

---

### Q: Difference between `app.use()` and route middleware?

```js
app.use(auth);
```

Runs for all routes.

```js
app.get('/profile', auth, handler);
```

Runs only for `/profile`.

---

### Q: Can middleware modify request data?

Yes.

```js
const middleware = (req, res, next) => {
    req.user = {
        id: 1,
        name: 'John'
    };

    next();
};
```

Later:

```js
console.log(req.user);
```

## Senior-Level Interview Answer

```
Middleware is a function that sits between the incoming request and the final route handler. 
It can inspect or modify requests and responses, 
perform tasks 
such as 
authentication, 
authorization, 
logging, 
validation, 
rate limiting, and error handling, 
and 
then either pass control to the next middleware using `next()` 
or terminate the request by sending a response.
Middleware promotes code reusability, separation of concerns, and maintainability in Node.js applications.
```
