# Why Is It Called Lexical Scope?

JavaScript determines scope based on **where the function is written**, not where it's called.

```js
let name = "Global";

function outer() {
    let name = "Trideep";

    function inner() {
        console.log(name);
    }

    return inner;
}

const fn = outer();
fn();
```

Output:

```
Trideep
```

`inner()` remembers the scope where it was created.

---

# Most Common Interview Example

```js
function outer() {
    let message = "Hello";

    return function() {
        console.log(message);
    };
}

const fn = outer();

fn();
```

Output:

```
Hello
```

Even though `outer()` has already finished.

# Private Variables

Closures are often used to create private state.

```js
function createCounter() {
    let count = 0;

    return {
        increment() {
            count++;
        },

        getCount() {
            return count;
        }
    };
}

const counter = createCounter();

counter.increment();

console.log(counter.getCount());
```

Output:

```
1
```

You cannot do:

```
counter.count
```

because `count` is private.

# Real-World Uses

### 1. Event Handlers

```js
button.addEventListener('click', function() {
    console.log(userId);
});
```

The callback remembers `userId`.

---

### 2. setTimeout

```js
function greet(name) {
    setTimeout(() => {
        console.log(name);
    }, 1000);
}

greet("Trideep");
```

Output:

```
Trideep
```

The callback closes over `name`.

---

### 3. Memoization

```js
function memoizedAdd() {
    const cache = {};

    return function(num) {
        if (cache[num]) {
            return cache[num];
        }

        cache[num] = num + 10;
        return cache[num];
    };
}
```

`cache` survives between calls.

# Your Previous Example

```js
for (let i = 0; i < 3; i++) {
    arrfn.push(() => {
        console.log(i);
    });
}
```

Each arrow function forms a closure.

```
fn1 -> i = 0
fn2 -> i = 1
fn3 -> i = 2
```

Each function remembers its own `i`.

---

# Common Interview Trap

```js
for (var i = 0; i < 3; i++) {
    setTimeout(() => {
        console.log(i);
    }, 0);
}
```

Output:

```
3
3
3
```

Because all closures share the same `i`.

With:

```js
for (let i = 0; i < 3; i++) {
    setTimeout(() => {
        console.log(i);
    }, 0);
}
```

Output:

```
0
1
2
```

Because each iteration gets its own binding.
