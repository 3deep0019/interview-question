A **closure** is created when a function remembers and can access variables from its outer (lexical) scope even after the outer function has finished executing.

### Simple Example

```js
function outer() {
    let count = 0;

    return function inner() {
        count++;
        console.log(count);
    };
}

const fn = outer();

fn(); // 1
fn(); // 2
fn(); // 3
```

### What Happens?

When `outer()` runs:

```js
count = 0
```

It returns:

```js
function inner() {
    count++;
    console.log(count);
}
```

Normally, when a function finishes, its local variables are destroyed.

But because `inner()` still needs `count`, JavaScript keeps it alive.

Memory:

```
fn
 │
 ▼
inner()
 │
 ▼
count = 0
```

When:

```
fn();
```

Output:

```
1
```

Next call:

```
2
```

Next call:

```
3
```

The variable survives because of the closure.

# Real Definition

Interview Answer:

A closure is a function that retains access to variables from its [[5. Lexical Scope|lexical scope]] even after the outer function has completed execution. Closures are commonly used for data privacy, event handlers, callbacks, memoization, and maintaining state between function calls. The key idea is that the function keeps a reference to the variables, not a copy of their values.
