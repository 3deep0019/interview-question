## First Version (`3 3 3`)
```js
function outer() {
    const arrfn = [];
    let i;

    for (i = 0; i < 3; i++) {
        arrfn.push(function() {
            console.log(i);
        });
    }

    return arrfn;
}

arrfn[0]();
arrfn[1]();
arrfn[3]();
```

## What happens?

### Iteration 1

```js
i = 0

arrfn.push(function() {
    console.log(i);
});
```

Function created but **not executed**.

---

### Iteration 2

```
i = 1
```

Another function created.

---

### Iteration 3

```
i = 2
```

Third function created.

---

### Loop Ends

```
i = 3
```

Now all functions are stored:

```
fn1 -> console.log(i)
fn2 -> console.log(i)
fn3 -> console.log(i)
```

Important:

They don't store:

```
0
1
2
```

They store a **reference** to the variable `i`.

Memory looks like:

```
outer()
│
├── i = 3
│
├── fn1 ──┐
├── fn2 ──┼──► same i
├── fn3 ──┘
```

---

### Execution

```
arrfn[0]();
```

Looks up current value of `i`

```
3
```

Same for all:

```
333
```

## Second Version (`0 1 2`)

```js
function outer() {
    const arrfn = [];

    for (let i = 0; i < 3; i++) {
        arrfn.push(function() {
            console.log(i);
        });
    }

    return arrfn;
}

arrfn[0]();
arrfn[1]();
arrfn[3]();
```

Most people think:

> "Because let is block scoped."

That's true but incomplete.

---

## What actually happens?

JavaScript creates a **new binding** for `i` on every iteration.

Conceptually:

### Iteration 1

```js
let i = 0;
```

Closure:

```
fn1 -> i = 0
```

---

### Iteration 2

New variable created:

```js
let i = 1;
```

Closure:

```
fn2 -> i = 1
```

---

### Iteration 3

New variable created:

```js
let i = 2;
```

Closure:

```
fn3 -> i = 2
```

Memory:

```
fn1 ──► i=0

fn2 ──► i=1

fn3 ──► i=2
```

Now each function has its own copy.

---

### Execution

```js
arrfn[0]()
```

Output:

```
0
```

---

```js
arrfn[1]()
```

Output:

```
1
```

---

```js
arrfn[2]()
```

Output:

```
2
```

---

# Why Doesn't `let` Print `3 3 3`?

Special behavior of `for` loops.

This:

```js
for (let i = 0; i < 3; i++)
```

is roughly equivalent to:

```js
{
   let i0 = 0;
   fn1 closes over i0;
}

{
   let i1 = 1;
   fn2 closes over i1;
}

{
   let i2 = 2;
   fn3 closes over i2;
}
```

Each iteration gets its own lexical environment.

---

# Interview Answer

If the interviewer asks:

> Why does the first print `3 3 3` and the second print `0 1 2`?

Answer:

In the first example, all closures capture the same variable `i`. After the loop finishes, `i` becomes 3, so every function prints 3. In the second example, `let` inside the `for` loop creates a new binding for each iteration. Each closure captures its own iteration's variable, so the functions print 0, 1, and 2 respectively.
