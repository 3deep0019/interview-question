```js
demo()

console.log(a);

console.log(b);

  

var a = 10;

let b = 20;

  

function demo() {

var a = 100;

let b = 200;

console.log(a);

console.log(b);

}
```

### The Output

If you run this code, this is exactly what will happen in the console:

Plaintext

```
100
200
undefined
ReferenceError: Cannot access 'b' before initialization
```

_(Note: Because of the `ReferenceError`, the script will crash and stop running at `console.log(b)`)._

### Why this happens (Step-by-Step)

JavaScript executes in two main phases: a **Creation/Memory phase** (where it scans for variable and function declarations) and an **Execution phase** (where it runs the code line by line). This behavior is called [[2. Hoisting|Hoisting]].

Here is how your specific code is processed:

**1. `demo()`** Because function declarations are completely hoisted (moved to the top of their scope along with their contents), you can call `demo()` before it is defined in the code.

- Inside the function, local variables `a` and `b` are created and initialized.
    
- `console.log(a)` prints **`100`**.
    
- `console.log(b)` prints **`200`**.
    
- These variables are scoped _only_ to the function and don't affect the global `a` and `b`.
    

**2. `console.log(a)`** You are trying to log the global variable `a` before the line `var a = 10;` has executed.

- Variables declared with `var` are hoisted to the top of their scope, but they are initialized with the value **`undefined`**.
    
- JavaScript knows `a` exists, but it hasn't assigned the `10` to it yet.
    
- Therefore, it prints **`undefined`**.
    

**3. `console.log(b)`** You are trying to log the global variable `b` before the line `let b = 20;` has executed.

- Variables declared with `let` (and `const`) are also hoisted, but they are placed in what is known as the [[1. Temporal Dead Zone (TDZ)|Temporal Dead Zone (TDZ)]] until the code execution actually reaches their line.
    
- Because `b` is in the TDZ, JavaScript refuses to let you interact with it.
    
- This throws a **`ReferenceError`** and halts the rest of the program.
