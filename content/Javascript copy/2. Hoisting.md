**Hoisting** is an invisible step that happens right before your JavaScript code actually runs. During this compilation phase, the JavaScript engine scans your code and "hoists" (lifts) variable and function _declarations_ to the top of their respective scopes.

However, a crucial rule to remember is that **JavaScript only hoists declarations, not initializations (assignments).**

Here is how hoisting affects different types of code.

## 1. Function Declarations (Fully Hoisted)

Function declarations are hoisted completely—both the function's name and its actual body are moved to the top. This is why you can call a function before it is physically written in your script.

```js
// What you write:
sayHello(); 

function sayHello() {
    console.log("Hello!");
}

// What the engine sees:
function sayHello() {
    console.log("Hello!");
}
sayHello(); // Works perfectly
```

## 2. `var` Variables (Partially Hoisted)

Variables declared with `var` are hoisted, but they are immediately initialized with a default value of `undefined`. The actual data you assign to the variable stays exactly where you wrote it.

```js
// What you write:
console.log(score); 
var score = 100;

// What the engine sees:
var score; // Initialized to undefined
console.log(score); // Prints 'undefined'
score = 100; // Assignment happens here
```

## 3. `let` and `const` (Hoisted to the TDZ)

As we saw with the [[1. Temporal Dead Zone (TDZ)|Temporal Dead Zone (TDZ)]], variables declared with `let` and `const` _are_ hoisted to the top of their block, but they are completely uninitialized. You cannot interact with them until the engine evaluates the line where they are defined.

```js
console.log(points); // ReferenceError!
let points = 50; 
```

## 4. Arrow Functions and Function Expressions

Hoisting gets tricky when you assign a function to a variable. The hoisting rules follow the variable type (`var`, `let`, or `const`), not the function itself.

```js
// Using var:
console.log(greet); // Prints 'undefined'
greet(); // TypeError: greet is not a function

var greet = function() {
    console.log("Hi!");
};

// Using const with an arrow function:
fly(); // ReferenceError: Cannot access 'fly' before initialization

const fly = () => {
    console.log("Flying!");
};
```
